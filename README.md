# MacroPro-Mac · 宏工具独立版

用于 macOS 的轻量鼠标点击录制与循环回放工具。把重复的点击操作录制一次，保存为本地 JSON 文件，再按指定次数或持续循环执行。

**当前版本：1.1 测试版。** 已完成本机启动和旧文件格式检查，但仍有“系统权限已开启，App 显示未允许”的未解决反馈。暂不承诺所有设备上可正常录制或播放。

## 功能

- 记录鼠标按下的位置和时间，回放为左键点击。
- 开始、停止录制与播放，提供全局快捷键。
- 指定循环次数或无限循环。
- 保存与加载本工具的 JSON 录制文件。
- 显示权限检测结果、文件校验错误和点击发送进度。
- 独立 App 内置 Python，启动时不显示终端窗口。

目前不记录键盘输入、拖动、滚轮和鼠标移动轨迹。右键等按下事件也会按左键回放，因此请仅录制左键操作。本项目不是 KeymouseGo 的分支，脚本格式与其不通用。

## 安装

适用于 **Apple 芯片（M 系列）、macOS 15 或更新版本**；Intel Mac、Windows 和 Linux 不在当前安装包支持范围内。

1. 在 [Releases](https://github.com/wjy23443200/MacroPro-Mac/releases) 下载测试版 ZIP 安装包并解压。
2. 退出此前运行的宏工具，将 App 放到固定位置（建议“应用程序”文件夹）。
3. 双击运行，无需另装 Python 或 Homebrew。
4. 按下文开启系统权限，完全退出后重新打开 App。

安装包采用本地临时签名，未经过 Apple 公证。若系统阻止启动，请在确认文件来源后通过系统设置中的“隐私与安全性”处理提示。

## 使用方法

### 基本操作

1. 把目标窗口摆放好，保持录制与播放时的分辨率和窗口位置一致。
2. 按 **F8** 开始录制，然后进行需要重复的左键点击。
3. 按 **F9** 停止录制。使用快捷键可避免把“停止录制”按钮本身录进去。
4. 点击“保存”，选择 JSON 文件位置。
5. 第一次测试请取消“无限循环”，将次数设为 **1**。
6. 按 **F6** 或点击“开始播放”；按 **F7** 或点击“停止播放”中止。

### 加载已有文件

点击“加载”，选择本工具此前保存的 JSON 文件，再点击“开始播放”。加载本身不会自动执行。文件中的时间是从录制开始计算的，因此播放前可能需要等待第一条记录的时间。

新录制会清空当前内存中的记录；需要保留时请先保存。播放前应调整好目标窗口，避免坐标落到其他按钮上。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| F6 | 开始播放 |
| F7 | 停止播放 |
| F8 | 开始录制 |
| F9 | 停止录制 |

如果功能键触发音量等系统功能，请使用 **Fn + 对应功能键**。全局快捷键需要系统权限；权限未生效时可先通过窗口按钮查看日志。

## 权限与常见问题

在“系统设置 → 隐私与安全性”中，为实际运行的 **宏工具独立版** 开启：

- **辅助功能**：允许发送鼠标操作。
- **输入监控**：用于录制和监听全局快捷键。

给终端或 Python 的授权不等于给独立 App 授权。修改权限后，请完全退出并重新打开 App。

### 开关已打开，仍提示未允许

这是当前仍待解决的问题，可能涉及重新打包后的签名变化或旧授权记录。可以尝试：退出 App，在两个权限列表中移除旧的同名项目，重新添加当前实际运行的 App 并开启，再启动。此方法尚未确认能解决所有情况。

若仍失败，请提交系统版本、芯片型号、App 版本及完整日志，避免反复重新安装。

### 显示点击已发送，但目标没有反应

“已发送”只代表程序调用了点击接口，不代表目标应用已成功响应。请检查权限、目标窗口位置、显示器布局与缩放是否变化；确认加载的是本工具的文件。

## 脚本格式

UTF-8 JSON 数组，每条记录包含三个数字字段：

```json
[
  {"x": 300, "y": 200, "time": 1.0},
  {"x": 400, "y": 250, "time": 2.5}
]
```

- `x`、`y`：屏幕坐标。
- `time`：距离录制开始的秒数，非负且按时间递增或相等。
- 上例在开始后约 1 秒点击一次，再等待约 1.5 秒点击第二次。

示例只是格式说明，不应在未确认位置时直接执行。

## 从源码运行

需要 macOS、Python 3.11 和可用的 Tkinter：

```sh
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python macro_pro.py
```

若 Python 缺少 Tkinter，请安装对应的 Tk 支持。源码启动时，系统权限可能归属于启动它的终端或 Python。

## 构建独立 App

在目标 Mac 架构上运行：

```sh
python -m pip install -r requirements-build.txt
python -m PyInstaller --noconfirm MacroPro.spec
```

输出位于 `dist/宏工具独立版.app`。运行环境与依赖随 App 打包；公开分发前应保留第三方许可文本。正式分发还需考虑稳定的开发者签名、公证及更多设备测试。
